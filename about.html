A propos de Mon Site Git

Mon Site Git est un projet statique cree pour apprendre les bases de Git et du developpement web. Il comprend des sections sur la securite, les reseaux et le developpement, ainsi qu'une section d'actualites pour les mises a jour.

Ce site a ete developpe en utilisant HTML, CSS et JavaScript, et est destine a servir de ressource pour les debutants qui souhaitent se familiariser avec Git et les concepts fondamentaux du web.
